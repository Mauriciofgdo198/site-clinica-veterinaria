# Site Clínica Veterinária

Site institucional responsivo para uma clínica veterinária, feito com HTML, CSS e JavaScript.

## Como visualizar

Abra `index.html` no navegador. O site não precisa de etapa de build.

## Estrutura

- `index.html`: conteúdo e seções do site.
- `css/styles.css`: estilos, layout e animações.
- `js/`: interações e dados dos serviços.
- `assets/`: imagens, ilustrações, ícones e logo.
